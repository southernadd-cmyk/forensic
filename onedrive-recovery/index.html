Start with safe test files

You will use your real college OneDrive. We will only change two practice files you create yourself.

Safety rule — read this firstDo not delete or roll back any genuine classwork, shared folders, or college data. Do not use the “Restore your OneDrive” whole-account feature. The only files you may delete or modify are the two practice files below.

Step 1 · Open OneDrive

Open Microsoft 365 ↗Open OneDrive ↗

Sign in with your college account. Select OneDrive and make a new folder named AAQ Recovery Lab in My files.

Step 2 · Make two Word test documents

Inside that folder, create these two new Word documents. Use New → Word document (or the equivalent in your college view).

STAGE 0212 minutesFile/data restore

Recover an accidentally deleted file

An employee has deleted a useful file. Your job is to restore it and prove the recovery worked.

Official Microsoft walkthroughKeep this open in another tab if you need help. Restore deleted files in OneDrive ↗
  1. Open your AAQ Recovery Lab folder.
  2. Find Practice-RecycleBin.docx. Select it and choose Delete. Only delete this test file.
  3. Go to the OneDrive Recycle bin, normally in the left-hand navigation.
  4. Select Practice-RecycleBin.docx and choose Restore.
  5. Return to AAQ Recovery Lab. Open the document and confirm the original sentence is present.
You can also paste a screenshot into Class Notebook separately.
STAGE 0318 minutesFile/data restore

Undo the wrong changes

Imagine that incorrect information was saved over a previously correct document. Find the earlier version and recover it.

Official Microsoft walkthroughRestore a previous version of a file ↗
  1. Open Practice-VersionHistory.docx in Word for the web.
  2. Replace the first and last lines so that the document now says Version 2 and the incorrect information below. Do not edit any other file.
  3. Allow Word to save, then close the file. Wait a short while before checking its Version History.
VERSION 2 — INCORRECT INFORMATION Assessment date: CANCELLED Student records: confidential Backups are no longer necessary.
  1. Back in OneDrive, right-click (or choose the ... menu for) Practice-VersionHistory.docx and select Version history.
  2. Find an earlier saved version showing the approved information. Select Restore for that version.
  3. Reopen the file and check that Friday and Backups must be checked regularly are back.
Can't see Version History?Make sure the document is in OneDrive, not only on the desktop. Close/reopen the document, wait for saving to finish, and check again. Your college may restrict Version History. If it is unavailable, read Microsoft's instructions and complete the questions below — do not alter any other files.
